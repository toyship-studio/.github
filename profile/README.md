# Toyship Studio

A small game studio. We build Panda, the engine and editor we make our games with, and work on
games of our own and with partners.

## Panda Engine

A cross-platform 2D and 3D game engine with its own editor, written in C++20. Free and
source-available under the Panda Engine License.

- **Download** the editor for macOS, Windows and Linux: [pandaengine.dev/download](https://pandaengine.dev/download)
- **Documentation**: [pandaengine.dev/docs](https://pandaengine.dev/docs/)
- **Source**: [toyship-studio/Panda](https://github.com/toyship-studio/Panda)
- **Questions and ideas**: [Discussions](https://github.com/toyship-studio/Panda/discussions)

Panda is in early development: preview builds come out often, and APIs and file formats still
change.
